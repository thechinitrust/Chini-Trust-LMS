# 1. Overall Vision and Objectives of the LMS
The LMS aims to create an accessible, evidence-based learning platform focused on neurodiversity, inclusive education, and mental well-being. It will provide structured, self-paced learning through expert-led courses, practical resources, and assessments that empower learners to build knowledge and apply inclusive practices in real-life settings.

While teachers are the primary audience for the initial launch, the platform is designed to be scalable and cater to a broader community, including caregivers, parents, students, mental health professionals, therapists, educators, and anyone interested in understanding neurodiversity and inclusion.

## 2. Expected Features and User Journeys

### Core Features
* User registration and login (must have)
* Course catalogue (must have)
* Structured courses with modules and videos (must have)
* Progress tracking and resume learning (must have)
* Quizzes and assessments (nice to have)
* Certificates of completion (nice to have)
* Downloadable resources (where applicable) (nice to have)
* User dashboard (nice to have)
* Admin dashboard for managing courses, videos, users, and content (must have)

### Typical User Journey (End User)
* Register/Login + login management (password reset etc)
* Browse available courses (ideally with ability to sort/ filter) 
* Enrol in a course
* Complete modules and videos at their own pace
* Attempt quizzes and assessments (where applicable) 
* Track learning progress
* Download certificate upon successful completion

### Typical User Journey (Admin)
* Add/edit/delete course
* Add/edit/delete modules within each course 
* Add/edit/delete videos and other content within each module
* Manage users (if needed) 

## 3. Existing Content and Assets to be Included
The LMS will be built around the content that is currently being developed and curated. This includes:
* Expert lecture recordings and panel discussions.
* A structured curriculum organised into Courses -> Modules -> Videos.
* Supporting resources such as PDFs, presentations, and reference material (where applicable).
* Branding and visual identity of the organisation (The Chini Trust).
* Course descriptions, learning objectives, quizzes, and assessments as they are developed.

At present, the content team is converting long-form expert lectures into structured, module-based learning videos, which will serve as the core content for the initial launch of the LMS.

## 4. Key Pain Points the New LMS Should Address
The new LMS should:
* Provide a clear and intuitive learning experience for diverse users.
* Organise long-form lecture content into structured, bite-sized learning modules.
* Make it easy for administrators to upload and manage content without requiring technical support.
* Allow learners to easily track their progress and continue learning from where they left off.
* Be scalable so that new courses, learner groups, and features can be added over time.
* Offer a modern, user-friendly interface that supports long-term growth and maintenance.
* Ensure the platform is well-documented and easier to maintain from a technical perspective.

## Tech stack for the LMS
### Key criteria
